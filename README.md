📐 Metrica 360
 

Aplicativo Android de medição de ângulo inspirado no app Medidas (Measure) da Apple.

📖 Sobre
O Metrica 360 é um aplicativo desenvolvido por Fabricio Faustino com o objetivo de trazer para o Android uma ferramenta simples, moderna e precisa para medição de ângulos e nivelamento.

Inspirado na experiência oferecida pelo aplicativo Medidas da Apple, o projeto utiliza os sensores nativos do dispositivo para detectar inclinações em tempo real e exibir o valor com uma interface limpa e intuitiva.

O aplicativo nasceu da necessidade de disponibilizar aos usuários Android uma solução prática para tarefas do dia a dia, como nivelamento de superfícies, instalação de móveis, montagem de estruturas e medições rápidas.

✨ Recursos
📐 Medição de ângulos em tempo real
📱 Interface minimalista e responsiva
✅ Indicação visual quando o dispositivo está nivelado
🎨 Mudança automática de cores conforme a inclinação
⚡ Atualização instantânea dos valores
📲 Compatível com smartphones Android
🔋 Baixo consumo de recursos
📸 Capturas de Tela
Nível perfeito (0°)
Metrica 360

Quando o dispositivo está perfeitamente nivelado, a interface destaca a medição utilizando uma cor verde para facilitar a visualização.

Inclinação detectada (-8°)
Metrica 360

O aplicativo detecta e exibe em tempo real a inclinação do dispositivo utilizando os sensores internos do Android.

🔧 Instalação
Clone o repositório:

git clone https://github.com/fabriciofaustino/metrica360.git
Abra o projeto no Android Studio e execute:

gradlew build
Ou gere o APK:

gradlew assembleRelease
